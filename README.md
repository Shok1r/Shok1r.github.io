# Колесо фортуны

Онлайн колесо фортуны на чистом HTML, CSS и JavaScript, без библиотек и сборки.

**Сайт:** https://shok1r.github.io/

## Возможности

- Любое количество секторов (от 1 до 100) — по номерам или со своими названиями.
- Плавное вращение со случайным результатом; выпавший сектор подсвечивается.
- Выпавший сектор можно удалить, чтобы он не выпал повторно, или оставить.
- Удаление любого сектора вручную из списка и кнопка «Вернуть удалённые».
- Готовая конфигурация **«Что? Где? Когда?»**: 11 вопросов и «Черный ящик».
- Настройки сохраняются в браузере (`localStorage`) и переживают перезагрузку.
- Запуск колеса клавишей пробел.
- Адаптивная вёрстка для телефонов и чёткая отрисовка на HiDPI-экранах.

## Запуск

Откройте `index.html` в браузере — сервер не нужен.

## Структура

| Файл | Назначение |
| --- | --- |
| `index.html` | Разметка, SEO-метатеги, описание для поисковиков |
| `style.css` | Оформление |
| `script.js` | Отрисовка колеса на canvas, вращение, управление секторами |
| `favicon.svg` | Иконка сайта |
| `robots.txt`, `sitemap.xml` | Файлы для поисковых систем |

## Как добавить свою конфигурацию

1. В `script.js` добавьте запись в объект `PRESETS`:

   ```js
   const PRESETS = {
     chgk: { ... },
     prizes: {
       title: 'Розыгрыш призов',
       sectors: ['Футболка', 'Кружка', 'Стикеры', 'Скидка 10%'],
     },
   };
   ```

2. В `index.html` добавьте кнопку в блок `.presets`:

   ```html
   <button id="presetPrizes" class="btn">Розыгрыш призов</button>
   ```

3. В `script.js` подключите обработчик и добавьте кнопку в `setControlsDisabled`, чтобы она блокировалась во время вращения:

   ```js
   const presetPrizesBtn = document.getElementById('presetPrizes');
   presetPrizesBtn.addEventListener('click', () => applyPreset(PRESETS.prizes));
   ```
